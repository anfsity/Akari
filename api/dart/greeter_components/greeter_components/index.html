greeter_components library

Optional reusable visual components for compiled Mozais themes.

StandardGreeterComponents implements the component identifiers used by the fallback theme. A theme opts into this factory explicitly; scene and SDK packages do not require it or prescribe its component identifiers.

Classes

StandardGreeterComponents
Optional component vocabulary shared explicitly by compiled themes. Slot-backed components listen to their own content; this factory binds semantic callbacks without owning authentication or rebuilding the full scene. A theme using different component IDs supplies its own factory.
