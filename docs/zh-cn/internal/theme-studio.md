# Theme Studio

Theme Studio 是面向已编译 Akari 主题的 Linux 场景编辑器。编辑器控件使用 `shadcn_flutter`；预览则通过 `SceneRuntime` 渲染所选主题自己的组件、token 和资源。

```sh
akari run studio --theme themes/default
# 不使用已安装的启动器：
fvm dart run tool/akari.dart run studio --theme themes/default
# 外部主题 package 也可采用相同方式：
fvm dart run tool/akari.dart run studio --theme /path/to/theme --jobs 2
```

`studio` 是 `run` 的一个目标。`akari run --help` 会列出目标，`akari run studio --help` 会显示其选项。如果当前 Shell 仍不支持补全，可使用 `akari install --shell zsh` 刷新安装脚本，然后在该 Shell 运行 `. ~/.local/share/akari/env.zsh`。bash 用户请使用 `--shell bash`，并加载 `~/.local/share/akari/env.bash`。

CLI 会解析主题、生成场景 Dart 代码，并在 `build/tool/hosts/<encoded-canonical-theme-path>/studio/` 中创建可复用宿主。编辑器使用模拟显示数据，不依赖后端或 D-Bus。生产宿主不依赖编辑器或其 UI library。`--dry-run` 会打印执行计划；`--format json` 和 `--report PATH` 使用通用工具报告约定。Studio 使用 debug 模式。Dart 和资源编辑通过现有热重载会话生效；保存场景 JSON 也会重新生成已编译场景。热重载会保留编辑器当前文档和撤销历史。使用 **Reload from disk** 可明确载入其他编辑器所做的更改。

Studio 接受 `--theme`、`--jobs` 及通用报告/dry-run 选项，不接受 `--mode` 或 `--backend`。命令和报告详情见 [CLI 参考](../reference/cli.md#commands-and-targets)。

## 编辑场景

拖动左侧边栏或右侧检查器旁的边界可调整宽度。拖动 **Scenes**、**Layers**、**Assets** 之间的水平边界，或检查器的标题、字段和操作区之间的边界，可重新分配面板空间。各列表独立滚动；最小尺寸会保证控件可用。当前会话中的设置变更和场景切换会保留面板尺寸。小窗口会为工作区提供滚动。

1. 从左侧面板选择场景。切换前须保存或放弃更改。**Load JSON** 会通过系统文件选择器打开任意场景 JSON，并在本会话的场景列表中加入该场景；它会使用当前编译主题的组件。文件无效时会保留之前的场景；继续操作前必须保存或放弃未保存修改。后续保存会写入打开的文件。导入和编译预览使用哪个 package，见[导入资源](#importing-assets)。
2. 在画布或图层列表中选择节点。列表也包含当前预览状态下不可见的节点，并按从前到后的顺序排列。
3. 在检查器中编辑参考像素（默认）或百分比形式的位置/尺寸、深度、绘制/焦点顺序、变换、动效，以及组件命名属性字段。**Advanced layout** 用于图层、缩放、平移、轴心和 3D 变换；**Advanced properties** 用于编辑完整的字符串属性 JSON。
4. 按 Enter 或离开字段即可应用到预览。动效选项会立即应用；也可按 **Apply to preview** 一次应用所有待处理字段。无效编辑会显示错误并保留最近一次有效文档。选择其他节点前，会先应用有效的待处理字段。切换布局单位只改变显示数值；它会保留待处理编辑，不会创建撤销记录。场景 JSON 仍保存归一化坐标；像素值依据 **Settings** 中的参考分辨率计算。
5. 使用 **Undo** 和 **Redo** 撤销/重做文档编辑。**Save scene** 会先应用待处理字段，再写入场景 JSON。**Reload from disk** 要求明确放弃当前更改，并会清除历史。

像素布局值使用场景参考画布，不随桌面缩放或编辑器缩放变化。对 1920×1080 画布，以下三种表达方式代表同一矩形：

| 字段 | Scene JSON | 像素 | 百分比 |
| --- | --- | --- | --- |
| X | `0.25` | `480` | `25` |
| Y | `0.25` | `270` | `25` |
| Width | `0.5` | `960` | `50` |
| Height | `0.25` | `270` | `25` |

更改参考分辨率会改变现有归一化矩形的像素表示，但不会将变换平移转换为百分比；变换使用的单位见[场景格式](../reference/scene-format.md#transforms)。

在图层面板中使用 **Duplicate node** 可复制所选节点的布局、变换、可见性、动效和属性。副本会被选中，并获得唯一 ID（`<id>-copy`、`<id>-copy-2` 等）。副本最初与原节点位置相同；可以在检查器中修改布局，也可在画布上拖动。**Delete node** 会删除所选节点，并在创作顺序中选中相邻节点。场景至少要保留一个节点，因此最后一个节点不能删除。两个操作都会先应用有效的检查器草稿，并在字段无效时停止。它们都支持撤销/重做及选择状态恢复；撤销删除会连同已应用的草稿编辑一起还原节点。只有明确保存后，更改才会写入磁盘。

预览会按场景参考分辨率渲染，再缩放以适应工作区。使用 **− / +** 缩放，使用 **100%** 切换为参考像素大小，或点击百分比/**Fit** 按钮适配并重新居中画布。Ctrl+鼠标滚轮会围绕指针缩放；普通滚轮用于平移。选择 **Hand** 或按住 Space 并拖动，可平移而不选择或编辑节点。缩放和平移不会记入文档历史。**State: Login / Dormant** 用于切换两种模拟显示状态。组件交互会被拦截并改为选择操作；节点命中测试遵循运行时的变换和可见性规则。选择画布工具后，可拖动一个可见节点：

- **Move** 会更改画布内的布局 X/Y。
- 在 **Move** 模式下，所选节点会显示八个缩放控制点。拖动边控制点会改变一个布局尺寸；拖动角控制点会同时改变两个尺寸。即使节点经过变换，对边仍会固定。按住 Shift 或开启锁定按钮可保持宽高比。改变尺寸会修改布局约束，使内容可以重新排布而不拉伸字形；自行执行适配缩放的组件仍可能缩小字体。控制点会保持屏幕显示尺寸，遵循网格吸附并停在画布边界。
- **Scale** 模式下，水平移动改变 Scale X，垂直移动改变 Scale Y；布局尺寸和轴心保持不变。镜像轴会保留正负号；拖动后的缩放绝对值介于 0.01 和 100 之间。对已通过 Scale 拉伸的节点，可选择 **Advanced layout → Reset scale** 将两个缩放轴恢复为 1，再使用控制点调整布局。重置会保留布局、平移、轴心和旋转，并支持撤销/重做。
- **Rotate** 会根据水平移动调整 Rotate Z，围绕创作轴心旋转。
- **3D rotate** 会根据水平移动调整 Rotate Y，根据垂直移动调整 Rotate X。创作透视会保留；可在检查器中编辑 **Perspective** 调整投影。

缩放控制点以节点渲染后的布局边界为基准，其中包含编译主题为可交互节点设置的最小命中区域。两个内置主题每个方向均使用 44 个参考像素。较小的创作矩形仍会按此最小尺寸渲染，因此拖动控制点会从可见边界开始，不能缩小到该尺寸以下。非交互节点最小可缩至一个参考像素。缩放为零或 3D 投影侧对观察者时不会显示控制点；请先在 **Advanced layout** 中恢复缩放或旋转。

一次完整拖动只创建一条撤销记录；检查器草稿无效时会阻止拖动，直到修正错误。所有工具都遵循画布坐标，即使节点旋转或缩放也一样。检查器中的位置、缩放和旋转字段会跟随实时预览更新，不会重建检查器或记录中间场景修订。取消拖动会同时还原画布和显示数值。

画布获得焦点时可使用以下快捷键。检查器文本字段仍保留其正常编辑行为。

| 快捷键 | 操作 |
| --- | --- |
| V | 移动/调整大小 |
| H | 手形工具 |
| K | 缩放 |
| R / Shift+R | 旋转 / 3D 旋转 |
| Space+拖动 | 临时平移 |
| Ctrl+鼠标滚轮 | 围绕指针缩放 |
| Shift+1 | 适配并重新居中 |
| 方向键 / Shift+方向键 | 移动 1 / 10 个参考像素 |
| Ctrl+Z | 撤销 |
| Ctrl+Shift+Z / Ctrl+Y | 重做 |
| Ctrl+D | 复制节点 |
| Delete | 删除节点，但至少保留一个 |
| Ctrl+S | 应用待处理字段并保存 |

编辑画布会禁用动画，使选择和属性检查保持稳定。

代码生成所用的编解码器也会校验编辑后的文档。保存时会先写入同目录的临时文件，只有完整写入后才会将临时文件重命名覆盖创作源文件。如果源文件在外部被修改，则拒绝保存；外部文件和编辑器中未保存的文档都会保留。

当前可通过复制节点创建新节点；尚不支持添加任意组件、编辑可见性规则、增加预览状态或关闭应用后恢复未保存内容。关闭窗口前请明确保存。自定义属性的名称和值由编译后的组件负责。

## 设置

**Settings** 可编辑画布参考宽/高、适配方式和安全区域策略，以及背景类型、资源、颜色、模糊和遮罩不透明度。这些更改会统一校验，支持撤销/重做，并且需要按 **Save scene** 才会保存。取消会保持原设置不变。video/custom 背景仍使用主题中编译的渲染器。

编辑器偏好包括浅色、深色或 **Follow system** 外观，以及 shadcn 配色预设（Zinc、Neutral、Slate、Stone、Blue、Rose、Violet）。深色预设使用柔和的背景以及凸起的卡片/弹出层表面。外观设置只影响编辑器；编译后的主题保留自己的预览颜色。旧版深色/浅色偏好会迁移，并保留已保存的选择。其他偏好包括显示画布网格、吸附网格和网格间距（4–512 个参考像素）。偏好会单独保存并在下次启动时恢复，不会令场景变脏。吸附作用于拖动节点的布局原点；如果画布边缘优先，可确保节点仍留在画布内。

## 导入资源

**Import asset** 会将文件复制到当前场景所属主题的 `assets/` 目录；如名称冲突，会另选新名称，并在保留已有条目和注释的同时，将该资源登记到主题的 `pubspec.yaml`。导入会立即写入；场景撤销不会删除文件。资源 package 路径会复制到剪贴板；点击资源名称可再次复制，以便填入组件属性。

**Use image** 会检查资源能否解码，并将其设为场景背景。该场景编辑支持撤销/重做，但需通过 **Save scene** 才会写入磁盘。Studio 会直接从磁盘读取当前场景的图像背景，因此新图像会立即出现。其他组件资源引用仍遵循编译时实现；若新 bundle 资源尚不可用，请重启 Studio。

**Load JSON** 会将打开的文件解析到最近的 package 边界。名称以 `theme_` 开头的 package 会拥有该场景的资源清单、导入操作和图像背景。非主题 package 边界，或没有 package 的文件，会使用编译主题的资源。加载其他主题的 JSON 会改变资源所有权，但不会将该主题的组件工厂编译进正在运行的编辑器。例如，`theme_other` 场景导入资源时会写入该 package 的 `assets/`，并保存以 `packages/theme_other/assets/` 开头的引用。使用 `--theme /path/to/theme_other` 重启 Studio，才能同时预览该 package 的组件。

## 编辑问题排查

| 现象 | 下一步 |
| --- | --- |
| 文本看起来被拉伸 | 使用 **Advanced layout → Reset scale**，再通过控制点调整布局 |
| 小型交互节点不能继续缩小 | 检查编译主题设置的最小命中区域；缩放只改变控制点呈现，不改变下限 |
| 字段修改或画布拖动无法应用 | 修正检查器报告的错误；文档操作会先应用并校验待处理字段 |
| 其他主题的 JSON 显示当前主题的组件 | 使用 `--theme` 指定其他 package 重新启动 Studio |
| 新导入的背景生效，但组件图片未显示 | 重启 Studio，将新资源编译进 bundle |
| 保存提示源文件被外部修改 | 先保留所需的未保存编辑，再通过明确的放弃/重载流程继续 |

场景文件和导入资源是创作源文件。CLI 会刷新生成的 `*.scene.g.dart`；不要通过编辑它来修复 Studio 保存问题。

## 检查

`akari verify` 包含 Studio 依赖解析、分析和测试。从 `packages/theme_studio` 也可运行针对性检查：

```sh
../../.fvm/flutter_sdk/bin/flutter analyze
../../.fvm/flutter_sdk/bin/flutter test
```
